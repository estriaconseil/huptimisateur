Noms : Mike → Test Mike  ·  Ami → Test Ami (évite de vous marcher dessus).

Ne pas utiliser le menu « Nouveau client / job ».

Temps de trajet

moins de 20 min = vert 20 à 40 min = orange (pas rouge) plus de 40 min = rouge

Comment noter un problème

Étape · Attendu · Obtenu · Capture oui/non. Signale tout de suite si ça bloque. Cosmétique : note et continue.

Partie 1 — Les 15 étapes (~25–35 min)

Prérequis : au moins 1 vendeur actif (domicile GPS) et 1 équipe d’installation.

1. Nouveau prospect avec GPS P0

Action Ventes → Pipeline prospects → Nouveau prospect. Nom = ton nom de test, tél. 819-555-0100, courriel demo@example.com. Adresse d’installation : cherche Places, clique une suggestion. Coche Même adresse que l’installation.

Attendu Pas d’écran « adresse déjà connue ».

Vérifier Le formulaire accepte l’adresse ; pas de message GPS manquant.

2. Booker le RDV vendeur P0

Action Sauvegarder et trouver un créneau → clique le créneau #1.

Attendu Retour pipeline, une seule carte, statut Visite planifiée.

Vérifier Pas deux cartes du même nom. Minutes vert / orange / rouge selon la légende.

3. Le calendrier ventes montre le bon RDV P0

Action Ventes → Calendrier ventes, date du créneau.

Attendu Le nom dans la bonne case, ville du chantier (pas « Prévu »), fond bleu.

Vérifier Pas un autre client dans ce créneau ; pas de #série / triangle orange.

4. Ouvrir le dossier et créer la soumission P0

Action Pipeline → carte → Créer soumission.

Attendu Page Créer soumission + nom. Adresses gelées. Modifier existe.

Vérifier Pas de Réassigner ; Bas de page en haut à droite. Croquis replié (« Ajouter un croquis »).

5. Remplir le minimum et sauvegarder P0

Action Durée Demi-journée (4 h). Unité 1 : marque Midea, sous-total 2500. Coche Répartir sans # série. Sauvegarder.

Attendu Message de sauvegarde ; Sauvegarder disparaît si tu n’as plus rien changé. Un numéro #30xxx apparaît.

Vérifier En bas : bouton Haut de page → ramène en haut.

6. PDF / courriel / répartir bloqués si non sauvegardé P1

Action Change le sous-total (ex. 2600) sans sauvegarder.

Attendu Aperçu PDF, Envoyer par courriel, Répartir grisés. Sauvegarder est visible. Après sauvegarde, les trois reviennent.

7. Pas d’envoi à 0 $ P1

Action Mets le sous-total à 0, sauvegarde.

Attendu Envoyer par courriel reste inutilisable.

8. Répartir vers l’installation P0

Action Remets 2500, sauvegarde. → Répartir vers l’installation. S’il y a un RDV vendeur : Annuler le RDV et répartir.

Attendu Dashboard installation ; job À planifier. La modale = Placer dans le calendrier, pas « Modifier le dossier ».

Vérifier Fermer la modale → tu restes sur le dashboard. Carte disparue du pipeline. Créneau ventes libre.

Bonus Sans bypass ni # série → Répartir. La page descend sur # Série. Tape un # ou coche bypass → le message disparaît.

9. Booker l’installation P0

Action Sur la carte → Placer dans le calendrier. Modale grande, onglets Meilleur créneau / Par calendrier. Prends la 1re suggestion, confirme.

Attendu Statut Réparti. Calendrier installation : bonne case, nom + ville chantier. Si bypass série : case jaune + #série.

Vérifier Une seule équipe / un seul créneau. Par calendrier sam/dim = semaine suivante.

10. Retrouver le client dans la base P0

Action Clients → Base donnée clients. Cherche le nom (ou la rue). Tape assez vite.

Attendu Une fiche, bonne adresse. Le dernier caractère de la recherche reste. Pas deux clients identiques.

11. Historique, adresse, soumission P0

Action Ouvre la fiche adresse.

Attendu Adresse, téléphone, job Réparti, numéro de soumission. Une ligne : statut · durée · # · Ouvrir.

Vérifier Le # est le même. Ouvrir amène à la soumission.

12. Nouvelle soumission = nouveau job, ancienne intacte P0

Action Fiche → Nouvelle soumission (pas Reprendre). Tu arrives sur Créer soumission. 4 h + sous-total 1800 → Sauvegarder.

Attendu Nouveau #. Ventes → Soumissions : les deux # existent. L’ancienne a encore 2500.

13. Reprendre ne copie pas les prix P0

Action Fiche → Reprendre la dernière soumission (prix à zéro).

Attendu Page soumission directe, nouveau #, unités copiées, sous-totaux à 0. L’ancienne (2500) n’a pas bougé.

14. Interception d’adresse connue P0

Action Pipeline → Nouveau prospect. Reprends exactement la même suggestion Places que l’étape 1. Choisis Même personne.

Attendu Fenêtre « adresse déjà connue ». Nouveau job Prospect, pas un deuxième client. Dans Clients : toujours une personne.

15. Corriger tél. / nom sans créer un 2e dossier P1

Action Sur la carte Prospect de l’étape 14 : crayon Modifier. Change le téléphone, Sauvegarder seulement.

Attendu Une seule carte, nouveau tél. Clients : toujours une fiche.

Partie 2 — Scénarios oraux

Après les 15 étapes, ou à la place si tu manques de temps. A est obligatoire.

Scénario A — Nouveau client simple

  1. Pipeline → Nouveau prospect (Test … A), Places neuve, Même adresse.
  2. Sauvegarder et trouver un créneau → créneau #1.
  3. Carte Visite planifiée → Créer soumission.
  4. 4 h + 2500 + Répartir sans # série → Sauvegarder.
  5. Répartir → Annuler le RDV et répartir.
  6. Modale Placer dans le calendrier (pas Modifier) → 1re suggestion → confirmer.
  7. Calendrier installation : le RDV est là, ville chantier, jaune #série si bypass.
  8. Clients → cherche → fiche → # + adresse.

Scénario B — Client existant

  1. Clients → fiche du scénario A. Note le # et le montant.
  2. Nouvelle soumission → autre prix (1800).
  3. Nouveau #. Ancienne inchangée.
  4. Fiche : deux jobs / deux #. Ne clique pas Reprendre ici.

Scénario C — Petite erreur

  1. Nouveau prospect, mauvais téléphone 111-111-1111, Places neuve, booker créneau #1.
  2. Crayon Modifier → bon téléphone → Sauvegarder seulement.
  3. Créer soumission. Si le nom est faux : Modifier dans la soumission puis sauvegarder.
  4. Pipeline : une carte. Clients : un client. Calendrier ventes : un RDV (pas un 2e).

Partie 3 — Extras si le temps le permet

Stop — corriger avant la démo

  • Places n’enregistre pas / pas de créneaux / erreur au bookage
  • Deux cartes ou deux clients pour la même personne
  • La soumission ne sauvegarde pas, ou Répartir refuse
  • L’ancienne soumission change de prix après Nouvelle soumission ou Reprendre
  • Répartir ouvre « Modifier le dossier » au lieu de Placer dans le calendrier
  • Le job n’apparaît pas dans Dashboard installation
  • Mauvaise équipe / mauvais jour / mauvaise ville au calendrier installation
  • Clients ne retrouve pas le nom, ou la recherche mange des lettres
  • 25 min affiché en rouge
  • Onglet encore nommé « Nouveau client »

Peut attendre

  • Croquis trop petit
  • Cap Long qui se remplit tout seul
  • Plus de 3 unités
  • Page Nouveau client / job
  • Libellés encore « projet » quelque part
  • PDF / courriel grisés tant que non sauvegardé (c’est voulu)
